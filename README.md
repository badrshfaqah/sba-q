# منصة متابعة جودة البث والمحتوى الإذاعي

منصة داخلية لإدارة جودة الإذاعات: تقييم البرامج (فني + محتوى)، متابعة الالتزام بهيكل البث،
تحليل الأداء، وإصدار تقارير ورسوم بيانية — PHP Native + MySQL، عربي RTL، متجاوب بالكامل.

## المتطلبات

- PHP 7.4 أو أحدث (مع امتدادات: pdo_mysql ، mbstring ، zip)
- قاعدة بيانات MySQL 5.7+ / MariaDB
- أي استضافة مشتركة عادية (cPanel / DirectAdmin) — بدون Composer وبدون Terminal

## طريقة التركيب

1. ارفع محتوى المجلد كاملاً عبر FTP أو File Manager إلى المجلد المطلوب
   (يعمل داخل مجلد فرعي مثل `/quality/` بجانب WordPress دون أي تعارض).
2. أنشئ قاعدة بيانات MySQL ومستخدماً لها من لوحة الاستضافة.
3. افتح رابط المنصة في المتصفح — سيظهر **معالج التثبيت تلقائياً**:
   - فحص متطلبات السيرفر
   - إدخال بيانات قاعدة البيانات واختبار الاتصال
   - إنشاء الجداول وزراعة البيانات الافتراضية
   - إنشاء أول مدير نظام وأول إذاعة
   - إنشاء ملف `config.php` وقفل التثبيت
4. سجّل الدخول وابدأ العمل.

> ملاحظة: إذا وُجد ملف `config.php` أو `install/installed.lock` من تركيب سابق
> فلن يعمل المعالج — احذفهما لإعادة التثبيت من الصفر.

## العضويات والصلاحيات

| العضوية | الصلاحيات |
|---|---|
| مدير النظام | كل شيء (مستخدمون، إعدادات، سجل عمليات، نسخ احتياطي) |
| مدير الجودة | كل البيانات + إدارة الإذاعات/البرامج/الحلقات + توزيع المقيمين |
| موظف | حسب الصلاحيات الممنوحة: تقييم فني / تقييم محتوى / التزام البث — يرى فقط ما يخصه |
| مشاهد | عرض فقط (لوحة القيادة والتقارير وشاشة الالتزام) |

## حساب النتيجة النهائية

```
Final Score = (Technical Avg × Weight) + (Content Avg × Weight)
```

الأوزان تُضبط من «الإعدادات» (الافتراضي 50% / 50%) ومجموعها يجب أن يساوي 100%.

## استيراد الالتزام من Excel

- الصيغ المدعومة: `xlsx` و `csv`
- الصف الأول: عمود «الوقت» ثم أعمدة بأسماء الإذاعات (مطابقة لأسمائها في النظام)
- القيم: `ملتزم` / `غير ملتزم` (أو 1 / 0 / نعم / لا) — الخلايا الفارغة تُتجاهل
- خياران: **إضافة** (تجاهل المكرر) أو **استبدال** (حذف بيانات اليوم ثم الإدخال)

## بنية المشروع (نواة + موديولات)

```
├── index.php            الموجّه الرئيسي
├── login.php / logout.php
├── presentation.php     صفحة تعريف النظام (عامة)
├── config.php           يُنشأ تلقائياً بواسطة المثبت
├── install/             معالج التثبيت (يقفل نفسه بعد الانتهاء)
├── core/                النواة: قاعدة البيانات، المصادقة، الصلاحيات،
│                        سجل العمليات، النسخ الاحتياطي، قارئ Excel، القالب
├── modules/             كل ميزة موديول مستقل:
│   ├── dashboard/       لوحة القيادة + مهامي
│   ├── stations/        الإذاعات
│   ├── programs/        البرامج
│   ├── episodes/        الحلقات + تعيين المقيمين
│   ├── quality/         نماذج التقييم (فني/محتوى)
│   ├── compliance/      شاشة الالتزام + الاستيراد
│   ├── reports/         التقارير (برنامج/التزام/مستخدمون)
│   ├── users/           المستخدمون والصلاحيات
│   ├── settings/        الإعدادات والمعايير والأوزان
│   ├── audit/           سجل العمليات
│   └── backup/          النسخ الاحتياطي والاستعادة
└── assets/              CSS + JS + الشعار (كلها محلية — لا CDN)
```

### إضافة موديول جديد

1. أنشئ مجلداً `modules/اسم-الموديول/index.php`
2. أضف سطراً في سجل الموديولات داخل `index.php` مع الصلاحية المطلوبة
3. أضف رابطاً في القائمة داخل `core/layout.php`

## ملاحظات أمنية

- كلمات المرور مشفرة بـ `password_hash`
- جميع الاستعلامات Prepared Statements (PDO)
- حماية CSRF على كل النماذج
- سجل عمليات كامل لكل الإجراءات الحساسة
- النسخ الاحتياطي والاستعادة من داخل المنصة بدون أدوات خارجية
